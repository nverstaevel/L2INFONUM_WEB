title: README and project folder
---
A **README** is the first file someone reads: what the project does, where the data comes from and under which licence, how to run it, its routes, and the help you received. Keep files in fixed places so that others find them.

## Example

```text
project/
  app.py
  requirements.txt     # packages to install
  README.md
  data/                # data files
  templates/           # HTML pages
  static/              # CSS, JavaScript, images
```

## Common mistakes

- A README that works only on your computer: test it on another one.
