## Token consumption

A **token** is a small piece of text (often part of a word) that an AI model reads or writes.

**The total for the whole course was not recorded.** The only figures measured cover 14 requests, made during the final review on 25 November 2026:

| Type of tokens | Number |
|---|---|
| New input | 28 |
| Written to the cache (context stored for reuse) | 96,146 |
| Read from the cache (context read again) | 2,760,153 |
| Output (text produced by the model) | 12,287 |
| **Total of this sample** | **2,868,614** |

This is a small part of the work, so the real total is higher. It must not be read as the cost of the course.
