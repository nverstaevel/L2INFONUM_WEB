title: Web & Open Data

Build a small website that presents European open data, from Python to HTML, CSS, JavaScript and Flask.
L2 Digital Studies & Management, Université Toulouse Capitole, 2026–2027.

**Common thread:** the Eurostat dataset [`tin00028`, internet use by individuals](https://ec.europa.eu/eurostat/databrowser/view/tin00028/default/table?lang=en).
