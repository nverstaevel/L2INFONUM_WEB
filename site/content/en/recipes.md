title: Recipes
---
Each recipe is a complete example that runs as it is, on a library. Copy it into a new folder, run it, then **change one thing at a time** to fit your data. Understand every line you keep: you must be able to explain it.

| Recipe | When to use it |
|---|---|
| [Set up a project](recipe-venv.html) | Start any Python project. |
| [Download a file](recipe-download.html) | Get a data file from the web with Python. |
| [Filter a CSV file](recipe-clean-csv.html) | Keep some rows and columns, with the right types. |
| [Compute figures and save them as JSON](recipe-stats-json.html) | Summarise a list of rows. |
| [A complete HTML page](recipe-page-skeleton.html) | Start any page. |
| [A table and a form](recipe-table-form.html) | Show data and ask for a choice. |
| [Readable page and tables](recipe-clean-style.html) | A simple stylesheet for any page. |
| [Responsive navigation bar](recipe-nav-bar.html) | A menu in a row on a computer, in a column on a phone. |
| [A chart from a JSON file](recipe-chart-from-json.html) | Draw data saved by Python. |
| [A Flask app with a template](recipe-flask-app.html) | Serve your first pages. |
| [A search form](recipe-search-form.html) | Filter data with a GET form. |
| [Remember a list with a session](recipe-session-list.html) | Favourites or basket, with a POST form. |
| [A JSON API and its chart](recipe-api-chart.html) | The page asks the server and redraws without reloading. |
| [A project README](recipe-readme.html) | Document the mini-project. |
