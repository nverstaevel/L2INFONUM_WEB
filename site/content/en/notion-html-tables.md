title: Tables
---
A table shows data in rows and columns: `table`, `caption` (title), `thead` and `tbody`, `tr` (row), `th` (header cell), `td` (data cell). Never use a table for page layout.

## Example

```html
<table>
  <caption>Books lent per month</caption>
  <thead><tr><th scope="col">Month</th><th scope="col">Books</th></tr></thead>
  <tbody><tr><td>January</td><td>120</td></tr></tbody>
</table>
```

## Common mistakes

- Rows with a different number of cells.
