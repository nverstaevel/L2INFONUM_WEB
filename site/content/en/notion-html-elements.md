title: HTML elements and attributes
---
**HTML** describes the content of a page with **elements**: opening **tag**, content, closing tag. An **attribute** gives more information in the opening tag. Elements are nested like boxes.

## Example

```html
<p>Read <a href="books.html">our books</a>.</p>
<!-- this is a comment -->
```

## Common mistakes

- A tag that is not closed, or closed in the wrong order.
