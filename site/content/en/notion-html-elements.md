title: HTML elements and attributes
---
**HTML** describes the content of a page with **elements**: opening **tag**, content, closing tag. An **attribute** gives more information in the opening tag. Elements are nested like boxes. `strong` marks something important, `em` a stressed word.

## Example

```html
<p>Read <a href="books.html">our books</a>.</p>
<p><strong>Closed on Monday.</strong> Loans last <em>three</em> weeks.</p>
<!-- this is a comment -->
```

## Common mistakes

- A tag that is not closed, or closed in the wrong order.
