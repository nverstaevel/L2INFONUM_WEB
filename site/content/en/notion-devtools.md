title: Developer tools
---
Every browser has tools to look inside a page: press `F12`. **Elements** shows the HTML and CSS, **Console** shows errors and lets you type JavaScript, **Network** lists every request with its status code and answer.

## Example

```text
F12                      open or close the tools
Ctrl+F5 / Cmd+Shift+R    reload without the cache (the browser's saved copy)
right-click → Inspect    see the HTML and CSS of an element
```

## Common mistakes

- Network tab empty: reload the page while it is open.
- Looking only at the page and not at the red message of the console.
