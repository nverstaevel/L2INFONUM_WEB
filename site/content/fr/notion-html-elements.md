title: Éléments et attributs HTML
---
Le **HTML** décrit le contenu d'une page avec des **éléments** : **balise** ouvrante, contenu, balise fermante. Un **attribut** ajoute une information dans la balise ouvrante. Les éléments s'emboîtent comme des boîtes.

## Exemple

```html
<p>Read <a href="books.html">our books</a>.</p>
<!-- this is a comment -->
```

## Erreurs fréquentes

- Une balise non fermée, ou fermée dans le mauvais ordre.
