title: README et dossier de projet
---
Un **README** est le premier fichier que l'on lit : ce que fait le projet, d'où viennent les données et sous quelle licence, comment le lancer, ses routes, et l'aide reçue. Rangez les fichiers à des places fixes pour qu'on les retrouve.

## Exemple

```text
project/
  app.py
  requirements.txt     # packages to install
  README.md
  data/                # data files
  templates/           # HTML pages
  static/              # CSS, JavaScript, images
```

## Erreurs fréquentes

- Un README qui ne marche que chez vous : testez-le ailleurs.
