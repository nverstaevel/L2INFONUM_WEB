title: Outils de développement
---
Chaque navigateur a des outils pour regarder dans une page : `F12`. **Éléments** montre le HTML et le CSS, **Console** affiche les erreurs et permet de taper du JavaScript, **Réseau** liste chaque requête avec son code d'état et sa réponse.

## Exemple

```text
F12                      open or close the tools
Ctrl+F5 / Cmd+Shift+R    reload without the cache (the browser's saved copy)
right-click → Inspect    see the HTML and CSS of an element
```

## Erreurs fréquentes

- Onglet Réseau vide : recharger la page pendant qu'il est ouvert.
- Regarder la page sans lire le message rouge de la console.
