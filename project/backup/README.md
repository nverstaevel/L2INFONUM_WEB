# Backup dataset / Jeu de secours

`co2_per_capita.csv`: CO2 emissions per person (tonnes), fossil fuels and industry, 27 EU countries, 2000-2025.
Émissions de CO2 par personne (tonnes), énergies fossiles et industrie, pays de l'UE.

- Columns / colonnes: `country` (two-letter Eurostat code, Greece is `EL` / code Eurostat à deux lettres, Grèce `EL`), `year`, `value`.
- Source: Global Carbon Budget (2026) and population data, processed by Our World in Data (https://github.com/owid/co2-data).
- Licence: Creative Commons BY 4.0. Cite the source and the producers. / Citez la source et les producteurs.
- Changes made / modifications: EU countries only, years from 2000, one column kept and renamed `value`, rounded to 2 decimals, names replaced by codes.
  Pays de l'UE seulement, années depuis 2000, une colonne gardée et renommée `value`, arrondie à 2 décimales, noms remplacés par des codes.
- Retrieved / récupéré le: 25 November 2026.

Use it only if your own dataset blocks you. / À n'utiliser que si votre propre jeu vous bloque.
