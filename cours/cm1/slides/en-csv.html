PYTHON AND FILES

Read a CSV file

import csv

with open("data/internet_use.csv", newline="", encoding="utf-8") as f:
rows = list(csv.DictReader(f)) # a list of dictionaries

print(len(rows))
print(rows[0]["geo"], rows[0]["TIME_PERIOD"], rows[0]["OBS_VALUE"])

Values read from a CSV file are text: convert them with float() or int().
